# @eq-labs/dashboard

Dashboard application for the EQ-LABS Engineering Ecosystem.

## Purpose

This application provides the web-based dashboard entry point for the
EQ-LABS Engineering Ecosystem.

## Current Status

This application was created during Phase 5 — Apps.

The current implementation is intentionally minimal and provides a functional
React application with an initial dashboard page.

No business functionality, ecosystem modules, authentication, navigation,
data visualization, or backend integration is implemented at this stage.

## Technology

The application uses:

- React.
- Vite.
- TypeScript.
- The shared EQ-LABS TypeScript configuration.
- The shared EQ-LABS Vite configuration.
