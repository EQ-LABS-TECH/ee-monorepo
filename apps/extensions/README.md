# @eq-labs/extensions

IDE extensions foundation for the EQ-LABS Engineering Ecosystem.

## Purpose

This application provides the structural foundation for future IDE
extensions associated with the EQ-LABS Engineering Ecosystem.

## Current Status

This application was created during Phase 5 — Apps.

The current implementation contains only the base application structure and
does not implement an IDE extension.

No IDE-specific commands, activation handlers, providers, user interfaces,
or integration logic are included at this stage.

## Configuration

The package uses the shared Node.js TypeScript configuration:

`@eq-labs/config-typescript/node`

## Development

### Typecheck

```bash
pnpm typecheck
```

### Build
