# @eq-labs/sdk

Software development kit for the EQ-LABS Engineering Ecosystem.

## Purpose

This package will provide the public development interfaces required by
applications and external consumers of the engineering ecosystem.

## Current Status

This package was created during Phase 4 — Packages.

No functional implementation is included at this stage.

## Configuration

The package uses the shared Node.js TypeScript configuration:

`@eq-labs/config-typescript/node`

## Development

```bash
pnpm build
pnpm typecheck
```
