# @eq-labs/shared

Shared package of the EQ-LABS Engineering Ecosystem.

## Purpose

This package provides shared components, types, and contracts that may be
consumed across multiple ecosystem packages.

## Current Status

This package was created during Phase 4 — Packages.

No functional implementation is included at this stage.

## Configuration

The package uses the shared Node.js TypeScript configuration:

`@eq-labs/config-typescript/node`

## Development

```bash
pnpm build
pnpm typecheck
```
